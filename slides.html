The problem

The scam is not in English

  • It arrives as a voice note from the boss asking for money urgently, or a WhatsApp message in Shona slang.
  • The usual phishing filters are written for Western email, need a subscription, and need the cloud — the one thing a parent will not have when it matters.
  • The cost of a wrong answer is not an inconvenience. It is someone's EcoCash balance.
  • The question is not "is this phishing". It is "what do I do in the next five minutes".

Target: the ordinary citizen. Also schools, clinics and small businesses.

How it works

A verdict you can argue with

01 · Read

Normalise Unicode, strip zero-width characters, expand chat shorthand (ur → your), undo leetspeak (p1n → pin, acc0unt → account).

02 · Weigh

28 weighted patterns score five threat classes, so the class with the most independent evidence wins — not whichever rule fired first.

03 · Resolve

Every URL is checked against 11 real Zimbabwean domains for impersonation, misspelling and lookalike subdomains.

04 · Explain

Signals sum to a risk score out of 10, and each one reports the exact words that triggered it — highlighted in the original message.

Deterministic. Inspectable. No model to download, no black box to trust.

Innovation 01

The scan ends at a report, not a verdict

Reference

CS-ZW-1WMAXAO — a content fingerprint, so the same message always produces the same reference and the case can be shown twice without changing.

Checklist

Not "be careful". Concrete steps per threat: call the number inside your own app, lock your mobile money if an OTP leaked.

Export

Plain text for the bank, JSON as an evidence bundle, Web Share with a WhatsApp hand-off. Generated in the browser — no server.

CYBER INCIDENT REPORT
Reference: CS-ZW-1WMAXAO
Threat: Dangerous link or file · Risk: High · Score: 9.0 / 10
Signals detected:

Recommended action:
  Do not open the link or file. Delete it and warn others.

Innovation 02

Local language, and no network required

Guidance in 3 languages

English, Shona and Ndebele for every threat class and every benign verdict, bundled in the app. Not machine translated at scan time.

Detection in 2 languages

11 rules catch Shona and Ndebele requests — ndiudze mharidzo, chikomo chako, ngicela ikhasi, iphini yami. Split so money asks score as financial and PIN asks as identity.

Installable, offline

Service-worker app shell. Load once, then it opens with the network off. 67 KB of code, no build step, no dependencies.

An English-only engine cannot catch the message your aunty actually receives.

Evidence

We scored ourselves first

100.0% threat accuracy on all 100 rows of the NUST training dataset
92.0% risk-level accuracy. All 8 misses are the same message repeated, and the threat type is still correct on it
0 benign messages wrongly flagged as threats
10/10 disguised scam set — slang, leetspeak, lookalike domains

Reproducible in the app: open the Lab tab. It scores itself on load.

Red team

Then we attacked ourselves

21 fresh Zimbabwean scams the engine was never tuned against — SMS slang, leetspeak, lookalike bank domains, a fake Ministry of Health allowance, boss voice-note transcripts. It catches 18.

The three it missesWhy
A voice note carrying only a pre-agreed code wordNo text rule can see it. This is the argument for a family code word.
Two on the phishing / malicious-link boundaryThe weight of the URL tips the class either way. A judgement call, not a bug.

Those three are in the app on purpose. Naming your own limits is the point.

Where it goes next

What we know is missing

  • Full Shona and Ndebele prose. Today we match request phrases, not whole sentences.
  • URL reputation and number intelligence. Both need a live service, and both would break the offline guarantee. Deliberate trade-off.
  • A code-word checker. The one thing our own red team beat us on.
  • Training on your own data. The Lab already scores any CSV with content, channel, threat_label, risk_level.

Four files. No build step. Open index.html — that is the install.
